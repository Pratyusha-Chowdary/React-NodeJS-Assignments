# Pre-Lab – React Introduction

## Objective

Become familiar with the basic structure of the React frontend project in your StudentMart application.

This is a preparation activity for your React lab.

---

## Instructions

Open your existing StudentMart >frontend part(where we installed our react project) in VS Code.

Go to:

src/

Observe the following files:

- App.jsx
- main.jsx
- App.css

---

## Task 1 – Explore the React Project

Identify the purpose of the following files:

1. App.jsx
2. main.jsx
3. App.css

Write one sentence about each file.

---

## Task 2 – Observe App.jsx

Open:

src/App.jsx

Observe the code carefully.

Answer the following questions:

1. What is the name of the component?
2. What does the component return?
3. Where do you see HTML-like code?
4. What is the purpose of `export default`?
