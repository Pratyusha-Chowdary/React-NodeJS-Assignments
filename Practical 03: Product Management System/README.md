# Practical 03: Product Management System

## Problem Statement

Develop a Product Management System with search and filtering features using React, Node.js, and MongoDB.

## Requirements

- Display products in a grid layout.
- Add products to MongoDB.
- Search products by name.
- Filter products by category.
- Sort products by price.
- View product details.
- Develop a responsive user interface.

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose

## Instructions to Students

1. Read the problem statement and understand the requirements.
2. Explore the frontend and backend code.
3. Understand how product data is stored and retrieved from MongoDB.
4. Test the search, filtering, sorting, and product details features.
5. Be prepared to explain and demonstrate the application during the lab session.

## Expected Outcome

A working Product Management System that allows users to add, display, search, filter, sort, and view product details, with product information stored in MongoDB.
